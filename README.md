# Gemini Voice Agent Website

Frontend for the deployed LiveKit agent `gemini-voice-agent`.

## Setup without installing Git

1. Create a LiveKit Cloud Development Token Server and copy its ID.
2. Open `src/main.jsx`.
3. Replace `PASTE_YOUR_TOKEN_SERVER_ID_HERE` with that ID.
4. Upload this project to GitHub.
5. Import the repository into Vercel.
6. Deploy.

This uses LiveKit's development token server for testing. For a public production app, use a protected token endpoint instead.
